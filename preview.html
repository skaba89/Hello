  • Claude Haiku + prompt caching (−80% coût)

WF1
Outreach Séquentiel
⏰ Cron toutes les 2h
  • Fetch prospects score ≥ 6, statut 'new'
  • Vérification quota (60 invites/jour max)
  • Claude Opus — message personnalisé 280c
  • Jitter aléatoire 45–90s (distribution Gaussian)
  • Playwright → envoyer invitation + note
LinkedIn Opus
WF2
Réponse DMs Auto
⏰ Cron toutes les 30min
  • Lecture DMs LinkedIn + Instagram en parallèle

  • Score < 9 → réponse auto contextuelle

🤖 Prompts Claude (A–E)

A
Message d'outreach
claude-opus-4-7 · max 400 tokens
Génère un message de connexion LinkedIn ultra-personnalisé (≤280 car), non commercial, basé sur un fait public spécifique. Paraît 100% humain.
→ "Bonjour Marie, votre article sur la transformation digitale chez TechCorp m'a interpellé — votre approche de l'omnicanalité résonne avec nos travaux actuels. Belle connexion ?"
B
Analyse de DM entrant
claude-opus-4-7 · JSON strict
Classe le message reçu : intent, urgency, score 0–10, key insights, action recommandée (reply/call/escalate/ignore).
→ {"intent":"hot_lead","score":9,"urgency":"high","suggestedAction":"escalate","requiresHuman":true}
C
Réponse DM automatique
claude-opus-4-7 · 2–4 phrases
Répond au DM de façon naturelle selon le score. Score <5 : engager. 5–7 : question. ≥7 : proposer un call 20min.
→ "Avec plaisir ! Ce serait plus simple en 20 min de call — tu as du temps cette semaine ou la prochaine ?"
D
Création de post
claude-opus-4-7 · JSON dual-format
Génère simultanément un post LinkedIn (150–300 mots, CTA soft) et Instagram (80–150 mots, storytelling) avec hashtags optimisés.
→ {"linkedin_post":"...","instagram_post":"...","hashtags_linkedin":[...],"hashtags_instagram":[...]}
E
Qualification prospect
claude-haiku-4-5 · batch rapide
Score ICP complet avec détection décideur, estimation taille entreprise, pain points probables, do_not_contact flag. Prompt caching activé.
→ {"score":8,"icp_match":true,"decision_maker":true,"company_size_estimate":"sme","do_not_contact":false}

🚀 Démarrage rapide

1
Configurer les variables d'environnement
cp .env.example .env # Générer les secrets openssl rand -hex 16 # → N8N_ENCRYPTION_KEY openssl rand -hex 24 # → PLAYWRIGHT_SERVER_API_KEY
2
Déployer tous les services
chmod +x scripts/deploy.sh scripts/backup.sh ./scripts/deploy.sh # Services démarrés : # http://localhost:5678 → n8n interface # http://localhost:3001 → Playwright API
3
Importer les workflows dans n8n
# Dans n8n : Workflows → Import from file # Ordre : WF5 → WF0 → WF1 → WF2 → WF3 → WF4 # Configurer les credentials : Claude API Key + PostgreSQL
4
Tester en dry-run, puis lancer
# Importer des prospects node scripts/add-prospect.js --csv prospects-template.csv # Ou via l'API webhook n8n curl -X POST http://localhost:5678/webhook/prospects/import \ -H "Content-Type: application/json" \ -d '{"prospects": [{"first_name":"Marie","linkedin_url":"..."}]}' # Désactiver le dry-run quand tout est validé sed -i 's/DRY_RUN=true/DRY_RUN=false/' .env && docker compose restart n8n
5
Mode développement (optionnel) — Playwright visible + interfaces DB
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d # Adminer (PG) : http://localhost:8080 # Redis UI : http://localhost:8081 # Playwright : navigateur VISIBLE pour déboguer
